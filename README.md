## 🏭 Manufacturing Reconciliation System

**Apache Kafka • Redis • PyFlink • Docker • Flask • Linux • SSE • Node-RED**

A real-time backend system for processing manufacturing inspection data and reconciling barcode flows across **AOI, SPI and FCR machines**.

### Architecture

```text
Manufacturing Machines
        │
        ▼
     Node-RED
        │
        ▼
      Kafka
        │
        ▼
     PyFlink
        │
        ▼
      Redis
        │
        ▼
    Flask API
        │
        ▼
   React Dashboard
```

### What I Built

- 📨 Designed **event-driven data pipelines** using Kafka and Redis
- ⚡ Implemented real-time stream processing using **PyFlink**
- 📊 Built metric aggregation and reconciliation logic
- 🔄 Implemented **24-hour tumbling window processing**
- 📡 Built live dashboard updates using **Server-Sent Events (SSE)**
- 🐳 Containerized backend services using **Docker Compose**
- 🏭 Designed processing for production monitoring, machine coverage and barcode reconciliation

🔗 [View Repository](https://github.com/NithinBrammesh/manufacturing-reconciliation-system)
